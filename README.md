# טריוויה שנות ה-80

אפליקציית אנדרואיד (WebView) עם מאגר שאלות על הסדרה "שנות ה-80".

- את קובץ ה-APK האחרון מורידים מדף ה-Releases של המאגר.
- כל דחיפה לענף `main` בונה APK חדש דרך GitHub Actions.
- `app/src/main/assets/index.html` – המשחק עצמו.
- `tools/` – הסקריפט שמייצר את מאגר השאלות ותבנית העמוד.
